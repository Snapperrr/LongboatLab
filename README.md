# 长船实验室 / Longboat Lab

面向 **Minecraft Java 1.21.1 / Fabric** 的原版船玩法重做模组。用船合成更长、更宽的连续船体，装上木铲船桨、巨大桨和五向河豚推进器，再用压缩弹跳、船桨钩爪与物理翻滚完成竞速。

**当前模组：0.10.19 · 随附地图：河豚盘山拉力赛 V12（最终交付副本）**。本工程可独立构建，不依赖同级其他模组项目。

## 运行依赖与兼容性

**有必需前置：Fabric Loader 和 Fabric API。没有其他必装的附属模组或第三方模型库。**

| 项目 | 要求 | 本工程配置 / 建议使用 |
| --- | --- | --- |
| Minecraft | Java 版 **1.21.1** | 1.21.1，不适用于基岩版 |
| Java | **21 或更高** | 建议 Java 21；编译需要 JDK 21 |
| Fabric Loader | **0.16.0 或更高** | 0.19.3 |
| Fabric API | **必需，必须选 1.21.1 对应版本** | 0.116.13+1.21.1，单独放入 `mods` |
| Longboat Lab | 客户端和服务端均安装 | 双方使用相同版本，当前为 0.10.19 |

依赖声明以 [fabric.mod.json](src/main/resources/fabric.mod.json) 为准，开发依赖版本见 [gradle.properties](gradle.properties)。Fabric API 没有打包进本模组 JAR；Fabric Loader 由启动器 / 服务端安装程序配置。

模型、贴图、HUD、音效和水面 shader 都随模组提供。**游玩不需要安装 Blockbench、GeckoLib、Cloth Config、Mod Menu、物理模组、额外资源包或外部光影包**。Blockbench 只用于编辑源模型；Python、Node.js 等工具也不是运行或普通 Gradle 编译的前置。

水面凹陷目前适配原版 Fabric 渲染路径。检测到 **Sodium 或 Iris** 时，会自动关闭自定义水面位移，保留原版水面和浪花等效果；它们不是必需依赖，也不会开启更完整的水面效果。其他渲染模组、资源包及“极佳”画质的组合尚未逐一验证。此模组直接修改原版船，可能与其他船体、驾驶或乘员系统重做模组冲突；不提供 Forge / NeoForge 版本。

## 安装模组

1. 在启动器中配置 Minecraft **1.21.1 + Fabric**，使用 Java 21。
2. 将本工程编译后的 `longboat-lab-0.10.19.jar` 和对应 1.21.1 的 Fabric API JAR 放进该启动实例的 `mods` 文件夹。不要使用 `-sources.jar`，更新时移走旧版 Longboat Lab JAR，避免重复加载。
3. 启动该 Fabric 实例。无需单独启用资源包或安装光影。
4. 联机时，每位玩家和 Fabric 服务端均安装同版本 Longboat Lab 与兼容的 Fabric API；单人游戏也必须装 Fabric API。

本仓库提供源码，**JAR 需先按下方步骤编译**。模组可在普通世界游玩，随附竞速地图是可选体验内容。

## 玩法与合成

### 连续长船与宽船

- 支持原版九种木材的船 / 竹筏；箱子船也使用改装、驾驶与乘员逻辑，但不参与船体扩展合成。
- 至少两艘**同材质、无箱子**的船放入不同合成格。只要输入不满足加宽条件且宽度相同，就将长度相加；一份船长的船体约长 2 格。配方无摆放形状限制，背包合成格也可使用放得下的配方。
- **加宽优先**：所有输入船长度相同且长度至少为 2 时，保持长度、相加宽度。例如两艘 `4×1` 合成 `4×2`；若想继续加长，可将 `4×1` 与 `1×1` 合成 `5×1`。尺寸写法为“长 × 宽”。
- 正常合成的长、宽各最多 **16**。合成保留改装件，不能混合普通桨与巨大桨；容量或巨大桨安装位冲突无法处理时，不会产生合成结果。
- 加长船物品默认以**压缩形态**放置，展开需要足够空间；带巨大桨的船保持展开。船体连续延展，内部横梁数量为长度减一。
- 加宽时船底、首尾板与横梁按实际宽度扩展木纹 UV，保持原版木纹大小，新增面积平铺材质。世界中的船、手持与物品栏预览使用同一模型，不把木纹横向拉长。
- 展开后的普通船最多提供 `2 × 长度 × 宽度` 个座位，箱子船为 `长度 × 宽度`；压缩后容量按一段船计算。对准附近空座位所在的船舱右键可上船，在船内同样可换座。

### 普通桨与巨大桨

| 操作 | 当前规则 |
| --- | --- |
| 安装普通桨 | 蹲下，手持木铲右键一侧船舷；一次安装**当前交互手中的整叠**，容量不足则保留余量，不读取背包其他木铲 |
| 普通桨容量 | 每侧最多 `16 × 长度 × 宽度` 根；指令生成可超出生存容量 |
| 划行动力 | 展开时计入全部桨；压缩时每侧最多按一根计算。两侧数量一致时使用原版转向速度，不一致时产生偏航，严重失衡会打转 |
| 巨大桨合成 | 将至少 **3 件木铲 / 巨大桨分放在不同合成格**，累计材料量决定尺寸；同一格叠放多把不算多个合成原料 |
| 安装巨大桨 | 蹲下对准船舷，安装到最近的空桨位；每舱每侧最多一根。不同大小巨大桨可共存，不能和普通桨混装 |
| 巨大桨碰撞 | 划动时可接触方块并施力，可辅助陆地移动；放置 / 展开也检查巨大桨空间。安装后不能压缩，空间不足时拒绝安装 |
| 拆桨 | 蹲下，持重锤瞄准桨右键。非创造模式返还对应木铲及其组件，满包掉到身边；创造模式不返还 |

两侧桨全部拆空后，普通划行不再提供动力，但浮力、惯性和已安装河豚的推力仍存在。木铲与河豚桶最多堆叠 **16** 件，仅数据相同的物品可合并。

### 河豚推进器

手持河豚桶瞄准船体会显示安装预览；**蹲下右键**可安装在船底、船头、船尾、左舷或右舷的网格位置，脸朝外。船底需要从下方瞄准；侧面可通过瞄准已有河豚继续向外或向上堆叠，压缩 / 展开保留原船舱和网格归属。

安装直接消耗河豚桶，**不返还空桶**。持重锤蹲下右键河豚即可拆除，非创造模式直接获得河豚桶，无需提前准备水桶；创造模式不消耗、不返还。河豚没有玩法数量上限，总数仍受存档整数范围与机器性能约束。

喷气为**按住喷、松开回充**，五个面独立蓄气，可组合喷射。对应面河豚越多，推力、气量和喷流规模越大；耗尽后先松开按键再回充。偏置安装产生翻滚力矩，推力方向随船体姿态变化。普通船桨不产生向上推进力，侧喷的升力需克服船与乘员的重量。

河豚沿嘴朝向喷气，船受到反向推力：**喷口朝下才向上助推**。垂直推力计入整船与乘员质量，多面喷射共享垂直合力预算，避免拆分到不同面重复获得升力加成；重力始终朝世界下方。侧喷原有水平力度保留，数量足够且姿态合适时仍可升空。这是游戏用简化推力模型。

### 弹跳、钩爪与水浪

压缩船可在有效接地 / 接水后发动弹簧跳跃，叠加船体越多跳得越高；起跳后提前展开会取消尚未释放的弹簧推力。钩爪从压缩船船头沿驾驶员视线发射，整条连接由刚性船桨组成，可锁定方块或实体并跟随移动；已锁定后下船不会自动收钩。

锁钩时 W/S 改变链长，方向键沿以锚点为中心、**当前链长**为半径的球面移动。射程随总桨数增加，当前最大为 192 格；无桨不能发射，已发射的钩爪需收回后才能再发射。

航行和拍水会产生船舷浪、尾迹、细水滴与半透明水雾。水面凹陷使用贴近原版水材质的局部视觉模拟；**不会改变水方块或将这些视觉波纹作为真实流体力反馈给船**。船体翻滚与碰撞属于服务端的简化刚体计算。

侧浪参考船头推水、压力沿船身衰减和浪尖破碎的现象制作：半透明水色浪面平滑回落，白沫只呈局部簇状出现在较陡的浪尖与外侧；长船转弯时，各船段向外推水会加强对应位置的浪花。水滴受重力下落，薄雾缓慢扩散沉降。拍水先翻起不规则弯曲水冠，上缘逐段破碎成飞滴，水膜约半秒内消散；河豚喷气使用羽化透明边缘与沿喷流方向拉伸的气体纹理。**多船尾浪高度已能叠加**：同一局部水位内最多 8 艘船向共享的 48×48 格高度场注入扰动，97×97 格点以固定 3 子步求解，有阻尼和限高；不会进行船只两两配对。装饰浪条各自衰减，不相互重算高度。该机制已有固定预算，两船叠加不会产生平方增长；实际 FPS 尚未实测。

按 **F8** 打开游戏内水面节点图，采用 Blender 节点编辑器式灰色画布、命名端口和属性侧栏。左键选择／移动节点，点击标题箭头折叠；中键或拖动空白处平移，滚轮缩放。Home 查看全部，小键盘小数点查看所选，N 开关侧栏，左右键切换节点，Esc 关闭。显示水面、船体压力、尾迹、飞溅和雾滴的实时信息。它是流程检查界面，不是 Shader 编辑器。管理员可热调河豚喷气密度／推力，见[命令说明](docs/commands.md#河豚喷气热调)。

## 默认操作

技能由驾驶员控制。可在 **选项 → 控制 → 按键绑定 → 长船实验室** 修改新增按键；划行和跳跃跟随原版绑定。

| 按键 / 交互 | 功能 |
| --- | --- |
| W / S、A / D | 前进 / 后退、转向 |
| 不蹲下，右键船舱 | 上船；乘坐时切换到附近空座位。船上瞄准箱子 / 工作台时优先使用方块 |
| R | 展开 / 压缩；巨大桨未拆除或空间不足时不能完成对应变形 |
| 空格 | 压缩船弹跳；钩爪已发射时优先解锁 / 收回 |
| G | 压缩形态发射钩爪，再按收回；可在空中发射 |
| 锁钩时 W / S | 收短 / 放长船桨链 |
| 锁钩时 ↑ ↓ ← → | 沿当前链长对应的球面移动 |
| 按住左 Alt | 所有已安装的河豚面共同喷气 |
| 小键盘 5 / 2 / 8 | 船底 / 船尾 / 船头独立喷气 |
| 小键盘 4 / 6 | 左舷 / 右舷独立喷气 |
| H | 开关自定义 HUD |
| J | 循环 HUD 大小：75%、100%、125%、150% |
| F7 | 乘船时开关稳定第三人称背面视角，可重新绑定 |
| 稳定视角下滚轮 / Shift + F7 | 调整镜头距离 / 重新对齐当前玩家朝向 |
| F8 | 打开水面节点展示界面，可重新绑定 |
| 蹲下 + 配件 / 重锤右键 | 安装配件 / 拆除瞄准的配件 |

数字喷气键指独立**数字小键盘**，不是键盘上排数字；无小键盘可自行重绑。HUD 设置保存在该游戏实例的 `config/longboatlab-hud.properties`。打开菜单或游戏窗口失焦时，驾驶技能停止接收有效操作。

稳定后视以进入时的玩家朝向为背面基准，此后跟随船体中心平移，保持世界朝向和水平线，不跟随玩家转头或船体翻滚、自转。滚轮调距范围 2.5～18 格，保留避墙；该模式关闭喷气 FOV 冲击。Shift 加自定义视角键可重新对齐，原版 F5 可直接切走；再次按视角键或下船恢复先前视角。菜单中的滚轮仍用于菜单操作。

### 单人 / 局域网导入

1. 将整个 `Puffer_Rally_Final` 文件夹复制到**当前启动实例的游戏目录**下的 `saves` 中，或将 ZIP 解压到该位置。
2. 确认结构为 `saves/Puffer_Rally_Final/level.dat`，不能再套一层同名文件夹。地图 ZIP 不是模组，不要放入 `mods`。
3. 使用上方列出的 Fabric 环境进入单人世界；双人游玩可开放到局域网，另一位玩家也要安装相同模组环境。
4. 本项目 Gradle 开发环境的存档路径是 `run/saves`；它与启动器的游戏目录可能不同。

地图所需数据包已经位于存档的 `datapacks/puffer_rally`，无需另外下载或拆出来安装。

### 独立服务器导入

在服务端关闭时，把 `Puffer_Rally_Final` 整个文件夹放到 Fabric 服务端根目录，在 `server.properties` 设置 `level-name=Puffer_Rally_Final`。服务器与玩家均安装 Longboat Lab、Fabric API；保留存档内的数据包。数据包调用模组救援命令需要 `function-permission-level=2` 或更高，默认值 2 即可。

### 赛道与比赛规则

总长约 **4.66 km**，双人共用赛道，支持单人练习。保留弹跳水闸、冰道、钩爪峡谷、弯曲窄道、两条 U 弯近道、约 1.02 km 盘山水道、隧道涵洞和终点港池，沿途有空中巨构、海岸珊瑚、山间村居与死火山口湖。

两位玩家站上出生港的青色 / 橙色平台开始，**10 秒倒计时后岸上发船，自行下水**。开局获得一格船、2 个河豚桶、4 把木铲和重锤，第一格快捷栏留空。黄色箭头指主线，绿色指近道；按顺序通过检查点，偏航会提醒。

四处补给水港可直接驶入，**水深一格，水面仍为 Y=63**；空手对准岸边服务箱右键。**每站只有一种资源，每位玩家每局各领一次**，背包放不下时不扣资格：

| 补给站 | 每位玩家可领取 |
| --- | --- |
| 绿色木铲港 | 木铲 ×6 |
| 蓝色木船港 | 船 ×2，旁边有工作台可在船内使用 |
| 第一个黄色河豚港 | 河豚桶 ×4 |
| 第二个黄色河豚港 | 河豚桶 ×4 |

使用发放的专用道具右键：指南针保留改装救援（+10 秒）、追溯指针换基础船（+20 秒）、绿宝石单练、羽毛退出、时钟在全员完赛后重开、书查看帮助。普通同名物品没有这些比赛功能。

开始 / 重置比赛会整理参赛者背包，重置还会清理旧比赛船、掉落物和河豚，并恢复个人补给资格。比赛道具无需选手拥有管理员权限。

## 调试命令

需要管理员权限等级 **2** 或开启作弊，木材名支持 Tab 补全：

```mcfunction
/longboatlab give 4 16 16 4 oak
/longboatlab spawn 4 16 16 4 oak
/longboatlab oar 2.5 2
/longboatlab rig give {Length:4,Width:2,LeftCount:2,RightCount:2,LeftSize:3d,RightSize:3d,SternPuffers:4}
/longboatlab physics
/longboatlab jets density 2
/longboatlab jets force 1.5
/longboatlab jets reset
```

前两条参数依次为“船长、左桨数、右桨数、船尾河豚数、木材”；`give` 给物品，`spawn` 直接生成实体。`oar` 给指定尺寸与数量的巨大桨。`rig` 默认使用巨大桨，可逐根指定大小和安装位置，也支持普通桨、多面河豚与船体姿态。`physics` 查看当前乘坐船的碰撞诊断。

完整语法、字段和可复制示例见 [调试命令参考](docs/commands.md)。指令可突破普通合成上限，但整数范围不是性能承诺；巨大桨仍受每舱安装位及每侧 512 根的指令分配限制，实体生成需通过空间与已加载区域检查。

## 编译与项目结构

使用 **JDK 21**，在此目录运行：

```powershell
.\gradlew.bat build
```

编译成功后安装 `build/libs/longboat-lab-0.10.19.jar`，不使用同目录的 `-sources.jar`。版本号随 `gradle.properties` 中的 `mod_version` 更新。Gradle Wrapper 随工程提供，首次构建需要联网下载 Gradle、Minecraft 和 Fabric 开发依赖。

```text
LongboatLab-1.21.1/
```

## 常见问题

- **提示缺少依赖或版本不匹配**：确认是 Java 版 1.21.1 / Fabric，Java 至少 21，并安装 1.21.1 版 Fabric API；客户端与服务器使用同版模组。
- **只有平水面，没有凹陷**：先检查是否安装 Sodium / Iris；当前会主动回退。shader 加载失败也会保留原版水面，查看 `logs/latest.log` 中的 `LongboatLab/Water` 信息。可通过 JVM 参数 `-Dlongboatlab.disableWaterSurface=true` 主动关闭位移效果。
- **上船或换座无响应**：不蹲下，对准附近船壳 / 空座位所在船舱；检查满员、变形、没顶及刚下船冷却。最新版已修复长船两端、倾斜船体选取和船内换座路径。
- **无法展开、装巨大桨或生成调试船**：展开后的船体与巨大桨必须有空间；超大尺寸或未加载的区域可能超过碰撞检查预算。巨大桨必须先拆空普通桨后安装。
- **船没有动力或一直偏航**：检查左右桨数；无桨无法划行，数量不一致会偏航。压缩形态最多按一对普通桨计算动力。
- **物品栏里的长船超出格子**：这是按真实尺寸显示的设计；整体模型已缩小 50%，长船仍会越出物品格。
- **改装船加箱子后丢失配置**：原版“船 + 箱子”配方不会复制自定义改装数据，不要用它转换已有改装船；可先用原版箱子船改装，或通过 `rig` 的 `Chest` 参数生成。
